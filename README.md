# AI Democracy

AI-assisted public cognitive infrastructure for democratic and multilateral governance.

The first demonstrator is **Observable UN**: a source-grounded dashboard that makes one United Nations mandate traceable from authorization through resources, implementation evidence, audit findings, outcomes, and unresolved disagreements.

## Core constitutional boundary

AI may organize, retrieve, compare, audit, forecast, and propose. It does **not** receive sovereign or coercive authority. Every substantive claim should remain traceable to public evidence, uncertainty and dissent should be visible, and missing links should be rendered as missing rather than inferred into existence.

## Current status

Greenfield repository initialized 2026-08-30. The first implementation case is UNMISS (United Nations Mission in South Sudan), using current public UN sources.
